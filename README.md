# 👾 Geek Store Stock

Sistema de controle de estoque e inventário especializado para a loja de colecionáveis e artigos da cultura pop **Geek Store**.

## 🎯 Objetivo do Sistema
Garantir o rastreamento preciso de produtos de tiragem limitada, colecionáveis e acessórios geek, prevenindo a falta de itens e controlando a entrada e saída de mercadorias.

## 🛠️ Tecnologias Previstas
- **Front-end:** HTML5, CSS3, JavaScript
- **Back-end:** Node.js
- **Banco de Dados:** MySQL / PostgreSQL
